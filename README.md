# carDrop

Конфигуратор перевозки вещей по России на Renault Master 2020.

## Возможности

- Выбор отправления и доставки по городам или кликом по карте.
- Построение автомобильного маршрута и расчёт примерной цены по тарифу 50 ₽/км.
- Автомобиль: цельнометаллический фургон до 2 т, кузов 3,7 × 2,2 × 1,7 м.

## Запуск

Откройте `index.html` через любой статический HTTP-сервер. Карта, геокодирование и маршрутизация требуют подключения к интернету.

Расстояние и геометрия маршрута запрашиваются у FOSSGIS OSRM на данных OpenStreetMap; поисковые подсказки городов используют Nominatim. Для небольшого трафика соблюдается лимит публичного сервиса маршрутизации — не чаще одного запроса в секунду.

Расчётная цена не учитывает автоматически ограничения дорог по высоте и массе фургона. Итоговые адреса, условия загрузки и стоимость нужно согласовать отдельно.

Границы России в `russia.geojson` основаны на Natural Earth. Подложка карты © OpenStreetMap.
