# carDrop

Конфигуратор перевозки вещей по России на тёмно-синем Renault Master 2020.

## Возможности

- Выбор адресов отправления и доставки по подсказкам Photon и Nominatim или по карте.
- Автомобильный маршрут и примерная цена по тарифу 50 ₽/км.
- Настройка числа грузчиков от 0 до 6; стоимость их работы согласуется отдельно.
- Renault Master, цельнометаллический фургон: до 2 т, кузов 3,7 × 2,2 × 1,7 м.
- Монохромная карта с выделенными границами России и зумом колёсиком мыши.

## Запуск

Откройте `index.html` через любой статический HTTP-сервер. Карта, геокодирование и маршрутизация требуют подключения к интернету.

Расстояние и геометрия маршрута запрашиваются у FOSSGIS OSRM на данных OpenStreetMap. Поиск адресов использует Photon и Nominatim. Публичные сервисы предназначены для умеренной нагрузки; массовое использование потребует собственного сервиса.

Расчётная цена не учитывает автоматически ограничения дорог по высоте и массе фургона. Итоговые адреса, условия загрузки и стоимость грузчиков нужно согласовать отдельно.

Границы России в `russia.geojson` основаны на Natural Earth. Подложка карты © OpenStreetMap.
