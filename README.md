# carDrop

Конфигуратор перевозки вещей по России на Renault Master 2020 в графитовом цвете.

## Возможности

- Выбор точных адресов отправления и доставки с подсказками Photon и Nominatim.
- Дорожный маршрут OSRM с полной геометрией без упрощения линии.
- Примерная стоимость по тарифу 50 ₽/км.
- Настройка числа грузчиков от 0 до 6.
- Дополнительные сведения о грузе, весе, объёме, этажах, лифте, дате и комментарии; сохраняются в браузере.
- Монохромная карта России с масштабированием колесиком мыши.
- Renault Master 2020, цельнометаллический фургон: до 2 т, кузов 3,7 × 2,2 × 1,7 м.

## Запуск

Откройте `index.html` через любой статический HTTP-сервер. Карта, геокодирование и маршрутизация требуют подключения к интернету.

Маршрут запрашивается у FOSSGIS OSRM на данных OpenStreetMap. Для рисования используется полная, несглаженная геометрия маршрута. Поиск адресов использует Photon и Nominatim; публичные сервисы подходят для умеренной нагрузки.

Расчётная цена не учитывает ограничения дорог по высоте и массе фургона. Итоговые адреса, условия загрузки и стоимость грузчиков согласуются отдельно.

Границы России в `russia.geojson` основаны на Natural Earth. Подложка карты © OpenStreetMap.
